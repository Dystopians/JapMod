# 日本地图日期滑块审计（0.1.0-alpha）

日期：2026-07-10  
游戏基线：Europa Universalis IV 1.37.5.0 Inca (491d)

## 结论

附属模组不再只抽查官方书签日。静态门禁逐日评估从 `1444.11.11`（含）到 `1821.1.1`（不含）的 **137,382 个可选日期**，并把 88 个日本省份的归属压缩为 **273 段连续区间**。

完整机器可读清单位于 `tools/jxp_map_validation/generated/ownership_intervals.csv`。每行记录省份、时间线来源、原版父省、起始日、结束日与所有者；相邻区间必须首尾相接，不允许空档或重叠。

## 三层保证

1. **原版继承层。** 40 个没有显式改写的既有省份，其根所有者及每个日期块中的所有者变化必须与本地 EU4 1.37.5 原版文件完全一致。
2. **细分规划层。** 40 个新增省份与 8 个有意改写的既有省份，必须逐项匹配 `history_plan.json` 中的显式时间线；日期必须递增、唯一、位于战役范围内，且不得重复设置同一所有者。
3. **逐日状态层。** 在每一个可选日期，30 个新增大名只要拥有日本领地，就必须拥有规划首都并恰有一个宗主；失去全部领地的当天起不得继续作为幽灵属国。国家实际拥有领地的连续区间还必须精确等于其规划的 `start` / `end`。

## 发展度

1444 年原版日本基线为税收 142、生产 125、人力 105，总计 372。细化版目标调整为税收 190、生产 168、人力 142，总计 **500**，增加 128（约 34.4%）。

- 本州、四国、九州核心省份最低总发展度为 5。
- 北海道、千岛、对马、飞驒、佐渡、隐岐、壹岐、奄美、先岛等边远地区最低为 4。
- 京都、大坂、江户、堺、博多、越后等中心另有显式下限。
- 分配器先满足层级下限，再按原版父省的税收、生产与人力权重分配余量；每次构建都必须精确闭合到 500。

## 仍需运行时确认

逐日静态验证能证明脚本状态连续且内部一致，也能证明未改写旧省与原版完全同轨；它不能证明每一个争议时期的封建控制存在唯一历史答案。当前显式时间线采用 EU4 的“单一省份所有者”抽象表达主要守护、战国大名与江户藩领，不把短期军事占领等同于永久所有权。

游戏启动仍需用户明确批准。获准后应在日期选择界面随机拖动年份，并重点抽查 `1456`、`1488`、`1523`、`1549`、`1568`、`1582`、`1600`、`1609`、`1622` 与 `1820` 前后的省份颜色、属国关系和国家首都。
