# 日轮诸道 0.8.0 阶段报告：建国分支政府改革

## 本阶段范围

- 0.7.1 收尾：补齐小大名事件、决议、理念、家族遗产进入 debug 清理链路。
- 0.8.0 重点：为每个日本建国分支扩展专属政府改革制度包。
- 仍保持兼容策略：不覆盖 `common/governments/00_governments.txt`，不使用 `replace_path`，路线改革通过事件/脚本效果自动授予。

## 已完成内容

- 新增 `common/government_reforms/jxp_18_route_reforms_extra.txt`。
- 每条路线新增 3 项改革，共 27 项：
  - 锁国神国：参勤交代道中、海岸番所、秘传洋书会。
  - 开国通商：银座会计所、异国炮术契约、敕许商馆网。
  - 吉利支丹日本：神学校与译馆、慈悲会病院、长崎护教水军。
  - 朱子礼制日本：诸藩讲学试、王化律令、三教评议所。
  - 王政复古日本：国学寮、国司再任制、王政亲征军。
  - 改革宗日本：印书会院、町会信约、契约商船队。
  - 海教日本：季风迪万、瓦合甫仓廪、香料护航众。
  - 一向一揆日本：惣门评定、门徒义仓、讲中足轻。
  - 倭寇日本：黑潮掟法、列岛自由港、跳帮船手众。

## 关键实现点

- `jxp_grant_route_reforms_effect` 已扩展为授予所有新改革。
- `jxp_clear_route_reforms_effect` 已扩展为清除所有新改革，防止路线切换残留。
- `events/jxp_realm_events.txt` 的隐藏补救事件 `jxp_realm.5` 已扩展，可为旧存档自动补发 0.8.0 新改革。
- `events/jxp_ikko_events.txt` 与 `events/jxp_wokou_events.txt` 的路线入口已改为调用统一授予函数，避免只授予旧单项改革。
- 新增 `localisation_source/jxp_18_route_reforms_l_english_utf8_source.yml` 与生成后的 `localisation/jxp_18_route_reforms_l_english.yml`。
