# 日轮诸道 0.6.0 阶段报告：建国分支政府改革

## 本阶段目标

- 以“每一个日本建国分支的特殊政府改革”为版本重点。
- 不替换原版 `common/governments/00_governments.txt`，避免因为接管政府改革层级而破坏兼容。
- 通过自动授予的 `basic_reform = yes` 制度包，为路线国家提供更鲜明、略强于原版泛用改革的长期国体特色。

## 已完成内容

- 新增 `common/government_reforms/jxp_14_route_reforms.txt`。
- 为九条建国路线各设计并注册 3 个特殊改革，共 27 个新改革：
  - 锁国/守护神国：武家诸法度、寺请宗门改、出岛目付。
  - 开国通商：朱印船评定众、兰学奉行所、开港会所。
  - 吉利支丹日本 `KJP`：十字朝仪、港町信众会、日轮十字卫队。
  - 朱子礼制日本 `CJP`：朱子学寮、礼籍户令、神儒合祀令。
  - 王政复古日本 `EJP`：太政官再兴、禁里亲卫、朝仪使节制。
  - 改革宗日本 `RFJ`：长老港务会、和兰书院、长老民兵约。
  - 海教日本 `SJP`：卡迪港奉行、朝觐海路护持、清真仓廪。
  - 一向一揆日本 `IJP`：门徒惣约、寺内町座法、乡中持枪众。
  - 倭寇海国 `WAK`：朱札私掠令、濑户内水先众、自由港掟书。
- 新增集中脚本：
  - `jxp_clear_route_reforms_effect`：切换路线时移除旧路线改革，防止叠加错误。
  - `jxp_grant_route_reforms_effect`：按路线/tag 统一授予对应改革。
- 已接入路线选择与转 tag 效果：
  - 锁国、开国路线在 `jxp_realm.1` 内直接授予。
  - `KJP/CJP/EJP/RFJ/SJP/IJP/WAK` 的路线切换效果均调用统一授予入口。
  - 朱子路线强制修复效果也会补发朱子制度包。
  - 调试脚本中的锁国、开国入口也会同步授予对应制度包，便于快速测试。
- 新增隐藏旧档补丁事件 `jxp_realm.5`：
  - 已经拥有路线旗标或路线 tag、但缺少 0.6.0 代表性改革的国家，会在读档后自动补发制度包。
- 新增并生成本地化：
  - 源文件：`localisation_source/jxp_14_route_reforms_l_english_utf8_source.yml`
  - 游戏读取文件：`localisation/jxp_14_route_reforms_l_english.yml`
  - 文案尽量采用 EU4 风格制度描述，不在正文直接写点数/百分比机制。
- 更新版本：
  - `descriptor.mod`
  - 外层 `japan_expanded_v2.mod`
  - 当前版本标记为 `0.6.0`。

## 与最初全局计划的对应

- 已推进：
  - “每条建国路线有独特国体与长期玩法”的目标。
  - “朱子、吉利支丹、伊斯兰、一向一揆、倭寇等分支不落回通用体验”的目标。
  - “机制显示与政府界面挂钩”的目标，目前通过自动 `basic_reform` 制度包体现。
- 未完成或仅部分完成：
  - 尚未接管原版可选政府改革层级，因此这些改革不是玩家在普通改革层级中手动选择的按钮。
  - 尚未为每条路线制作独立政府改革图标；当前复用 `shogunate` 图标，等待后续资源批量制作。
  - 尚未围绕这 27 个改革追加专属事件、任务分支和改革间互斥/升级链。
  - 尚未做 20-100 年观察局。

## 后续建议

- 如果需要“可手动选择的路线改革层级”，应新开一版专门合并 `common/governments/00_governments.txt`，并对比原版 1.37.5 后再落地，避免大面积覆盖风险。
- 0.6.x 的下一步可以把每条路线的三个制度包扩展为任务奖励、低频事件和政策互动。
- 图标资源应按 EU4 政府改革图标尺寸与通道格式单独生成并后处理，再替换当前统一图标。
