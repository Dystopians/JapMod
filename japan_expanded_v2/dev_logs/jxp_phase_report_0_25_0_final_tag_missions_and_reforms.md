# 日轮诸道 0.25.0：终局国体任务与改革修复

## 问题复盘

此前的校验只证明每个国家状态占有五个合法槽位，却没有衡量各列纵深。朱子礼制日本因公共两列延伸至第 27 行、第三和第四列止于第 10/11 行、第五列又孤立延伸至第 28 行，形成了截图所示的大段空白与孤线。CJP 与 EJP 还共用同一组三条路线列，RFJ 借用 KJP 的基督教列，WAK 借用 JAP 的神道列；这些内容虽非原版通用任务，却不足以表现终局国体身份。

## 本阶段实现

1. 将统一后公共国家列与宫廷列由稀疏的 `1,3,...,27` 压缩为 `1..14`。该布局采用 EU4 1.37.5 原版日本任务已验证的一行同列连接方式，跨列连接仍严格限制为相邻槽位和下一行。
2. 新增六个终局专属任务组：
   - CJP：神儒合礼列；
   - EJP：王政官制、朝廷礼仪、皇国海疆三列；
   - RFJ：盟约海疆列；
   - WAK：黑潮法度列。
3. 新增 30 个终局路线任务，并为未定国是的 JAP 增补 4 个任务。总量由 238 个任务、34 个任务组增至 272 个任务、40 个任务组。
4. 将原共享组收窄：神道分支只服务未定路线与锁国 JAP；基督教公共分支只服务 KJP；儒家分支和原礼制第五列只服务 CJP。
5. 修复 WAK 五处仍指向旧神道列的前置条件，并同步改写重排生成器所保留的旧逻辑图，防止机械重排恢复失效依赖。
6. 新增 `jxp_migration_v025.1`。旧档会在启动时校正缺失的终局路线 flag、同步理念与改革，并执行立即一次、次日一次的规范任务交换。

## 任务树硬性合同

- 每个统一后状态恰有五个自定义非通用任务组，槽位为 `1..5`。
- 每槽至少 5 个任务；路线槽 `3..5` 必须延伸到第 10 行或更深。
- 同一状态五列终点的最大差不得超过 5 行。
- 十种统一后状态必须具有不同的五任务组签名。
- 所有可见和隐藏前置都必须在该状态中有效；任何 active-to-inactive 前置直接阻止发布。

## 政府改革修复

- 保持 27 项路线改革与 38 项大名创始改革位于原版君主制前 11 级，不新增第 12 级以后层级。
- 新增十种统一后国家状态的改革可见性模拟：每条路线必须恰好显示自己的 3 项改革，未定路线不得泄漏其他路线改革。
- `jxp_grant_route_reforms_effect` 现在统一调用 `regenerate_government_mechanics = yes`，路线 flag 或终局 tag 改变后立即重建政府界面的可选改革。

## 兼容与附带修复

- 运行时任务指纹由 9 种路线扩展为 10 种，CJP 与 EJP 分别验证三条专属锚点。
- 新增中文文案文件 `jxp_56_final_tag_identity_missions_l_english.yml`，活动文件为 UTF-8 BOM 与 EU4SpecialEscape 格式，不含裸 CJK。
- 地图伴侣事件 `jxp_map.6` 的无效触发器 `year = 1543` 改为原版确认的 `is_year = 1543`。
- `eu4-modding` skill 新增终局纵深、唯一签名、共享列拆分和改革可见性规则。
