# 日轮诸道 0.23.1 儒教神道继承与界面兼容修复报告

日期：2026-07-09

## 问题根因

### 儒教日本无法完整继承神道事件

EU4 1.37.5 的神道事变只允许 `religion = shinto` 的国家使用，神道依赖孤立主义机制，儒教则使用和谐度机制。因此儒教日本不能直接继续运行原版事变界面，只能由普通事件链承接其主题与后续状态。

0.23.0 已有八条桥接链的雏形，但仍存在三处断点：

- 起始事件以 `is_incident_happened` 为禁用条件，导致“改宗前开始、改宗后中断”的事变反而无法接续；
- 新儒学与城市化链没有写回原版完成 flag，南蛮与铁炮链没有完整写回《霸业》任务读取的结局 flag；
- 自然触发等待时间较长，玩家无法确认桥接链究竟是尚未满足条件，还是已经失效。

### 神道融合重复

神道融合必须只由一个规范化 scripted effect 写入，并以 `NOT = { has_harmonized_with = shinto }` 保护。手工添加或删除 `harmonized_shinto` 修正会造成重复图标或状态脱节。

### 八纮一宇不可见

`jxp_hakko_ichiu_reform` 的 `potential` 与 `trigger` 同时要求解锁 flag，而任务奖励只有在完成任务时已经是天朝皇帝才写入该 flag。先完成“问鼎天命”、后夺取天命的玩家会永久看不见改革。

### 遗绪议定显示“触发 [] 事件”

五个遗绪 scripted effect 在可见层使用 `if` / `else_if` 动态分派事件。EU4 构建工具提示时尚不能确定最终事件 ID，因此显示空事件名。

## 已完成修复

- 保留唯一的 `add_harmonized_religion = shinto`，并为同一分支增加幂等保护校验。
- 为倭寇、城市化、一向一揆、新儒学、南蛮、铁炮、基督教传播与幕府权威建立八个统一可用性 trigger。
- 不再因 `is_incident_happened` 阻断改宗中途的接续，只在原版完成 flag 已存在或原版事变仍处于活动状态时停止桥接。
- 八条链结束时写回全部原版完成 flag。
- 南蛮、铁炮与基督教链写回原版/《霸业》日本任务读取的结局 flag，并清理互斥结局。
- 新增旧存档迁移事件 `jxp_confucian_incident.98`，补写 0.23.0 已完成桥接链缺少的原版状态。
- 新增普通玩家决议“续修神祇事变录”，以 25 行政点数触发下一条满足条件的未完成链；五年共享冷却防止事件堆叠，自然 MTTH 触发仍然保留。
- 儒教调试分类补齐八条桥接链的独立入口，每个入口都会重置该链状态后触发。
- “八纮一宇”对日本天朝始终可见；未完成“问鼎天命”时显示为锁定。
- “问鼎天命”只要拥有天命 DLC 就持久解锁改革，不再要求完成任务当下已经成为天朝皇帝。
- 新增 `jxp_celestial_compat.1`，为旧存档补写八纮一宇解锁状态。
- 五个遗绪效果保留资源消耗和稳定 `custom_tooltip`，把动态事件分派全部移入 `hidden_effect`。
- 版本号更新为 0.23.1，并重建可视化页面。

## 验证加强

- 发布验证器现在检查唯一且受保护的神道融合写入。
- 检查八个桥接起点、八个原版完成 flag、六个 DLC 结局 flag、旧档迁移和八个调试入口。
- 检查八条链的全部 12 条延时边；每个非终点事件的每个选项都必须在 1095 日后调度正确的下一节点，后续节点不得依赖首事件专用的冷却或 dispatch flag。
- 新增“八纮一宇与动态提示兼容”检查，防止改革再次被 `potential` 隐藏，或遗绪事件分派重新暴露在可见工具提示中。
- 日本原版任务覆盖生成器会同时向 `potential` 与 `potential_on_load` 写入 JXP 排除条件；发布检查会验证两层，防止原版任务组在 JXP 树加载时重新产生 series-overlap。
- 可视化器会忽略两份仅用于兼容的原版任务覆盖，只展示真正的 JXP 任务与本地化。
- EU4 modding skill 已记录上述原则，skill 自检通过。
