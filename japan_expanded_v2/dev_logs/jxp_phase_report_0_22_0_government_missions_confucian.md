# 日轮诸道 0.22.0 阶段报告

## 本阶段目标

本阶段集中处理三项长期结构问题：将路线政府改革收回原版前十一层；以原版与 Mod 的有效任务组共同计算任务树拓扑；重建朱子礼制日本的神道融合、神道历史事件桥接与儒教传播机制。

## 政府改革

1. 删除四个置于原版十一层之后的自定义改革层。
2. 将二十七项路线改革按制度主题分配到原版层级：官僚制、国家与宗教、军事学说、议政机关、行政扩张、经济事务、权力正当性、集权与宪政、权力分立等。
3. 将三十八项建国大名改革并入“世袭与贵族”层。各自的出身 flag 使同一国家只看到相符的一项，普通路线切换不会抹去建国家门记忆。
4. 可见路线改革不再由脚本自动授予，玩家必须在政府改革界面选择；脚本只保留不占层级的基础载体改革。
5. 新增一次性迁移事件 `jxp_migration_v022.1`。旧存档会清除旧路线层级选择、恢复基础载体、重建政府机制，并在最终国家状态确定后刷新任务树。
6. 使用 imagegen 制作二十七枚路线图标与八枚建国家系图标；最终资产为 57x57、32 位 RGBA DDS，并以 `government_reform_<icon_key>` 注册。

## 任务树拓扑

1. 确认原版界面只有五列。合法性按实际激活的 `(slot, position)` 判断；同一列的两个任务组只要占用行不重叠即可共存。
2. 修正幕府将军未被“大名阶段”识别、基础 JAP 未进入共享国家/朝廷任务、宗教兜底分支误激活等问题。
3. 重新启用并安置此前被 `always = no` 停用的朱子国内制度任务与家门议政遗产任务。
4. 为 `KJP/CJP/EJP/RFJ/SJP/IJP/WAK` 新增五列、第一至第八行的共同建国基础任务。转变国号后不再出现原版 JAP 基础任务消失而留下空白的情况。
5. 校验器直接解析并哈希锁定 `Japanese_Missions.txt` 与 `DOM_Japanese_Missions.txt`，将二十三个原版任务组和三十五个 Mod 任务组放入十一种国家配置共同验算。
6. 最终结果为一百八十七项 Mod 任务；所有路线均无格位冲突、缺失前置、逆向箭头、循环依赖或第六列。

## 朱子礼制日本

1. 神道融合现在只有一处实际变更：`jxp_confucian_sync_shinto_effect` 中受 `has_harmonized_with` 保护的 `add_harmonized_religion = shinto`。
2. 删除手工添加和调试移除 `harmonized_shinto` 的旧做法。该修正完全交由原版 `on_harmonized_shinto` 回调维护，因此不再产生双重融合。
3. 朱子路线离开神道教前，将原版锁国档位换算为“海门外学”的最低值，但绝不降低玩家已经通过 JXP 机制积累的更高数值。
4. 神道教的八类历史主题均有朱子礼制桥接：宋明理学、城市化、南蛮贸易、铁炮传播、基督教传播、幕府权威、一向宗与倭寇。已经完成或仍在运行的原版事件不会被重复触发。
5. 桥接事件继续改变天下秩序、天皇裁可与海门外学，并在适当结局设置原版任务使用的完成 flag。

## 儒教改革中心

1. 以 1.37.5 原版 `00_religion.txt` 为锁版基础，在 `confucianism` 中加入 `allowed_center_conversion = { shinto }`。
2. 新增 `confucianism_center_of_reformation`，只选择日本地区的神道教省份，并排除传教士、宗教中心、已有改革中心、宗教狂热与伊势。
3. 最多建立三个带 JXP 省份标记的原生改革中心。优先位置为山城、肥前与武藏，以覆盖畿内、九州和关东；缺省时再用首都与随机合法省份补位。
4. 伊势 `4359` 永久保持神道教。JXP 自己添加的宗教狂热另有省份 flag，调试清理只移除自己创建的状态。
5. 旧版伪改革中心会被迁移或清除；年度事件只监测传播完成，不再直接改宗省份。

## 校验结果

- `validate_eu4_mod.ps1`：通过，无警告或错误。
- `tools/jxp_validation/run_validation.py --verbose --game-root <EU4>`：八项检查全部通过。
- Clausewitz 脚本：162/162 解析成功。
- 任务：十一种有效配置全部合法；七个转变国号均没有误继承原版 JAP 任务组。
- 改革：27 项路线改革、38 项建国家门改革、306 项停放定义的注册状态正确。
- 本地化：55 个 active 文件均有 UTF-8 BOM，且无裸 CJK。
- 图片：35 项改革 DDS 的尺寸、通道、非空像素、sprite 与 texture 路径全部通过。

## 尚存风险

静态校验无法完全证明 EU4 引擎会在“国教已融合神道”的所有情况下仍让儒教改革中心转换神道省份；该点必须用新档与旧档分别进行游戏内观察。完整覆盖 `00_religion.txt` 也意味着与其他直接覆盖同文件的宗教大修存在版本与加载顺序冲突，需要在后续兼容阶段维护。

本次执行环境无权写入 Documents 下的实际 Mod 目录，因此以上成果位于可写的完整暂存副本，尚未覆盖启动器当前加载的版本。
