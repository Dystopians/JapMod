# 日轮诸道 0.23.0 阶段报告

## 本阶段目标

本阶段集中解决三项实测问题：任务树切换后只出现“获得新任务”提示却不刷新、任务排布长期退化为竖直列、七个日本终局路线国家理念明显弱于原版日本。

## 已完成

### 任务树刷新

- 35 个任务组全部加入 `potential_on_load = { always = yes }`，确保路线尚未成立时，其候选任务组也已被引擎预载。
- `swap_non_generic_missions = yes` 只保留一个可执行位置：隐藏事件 `jxp_mission_refresh.1`。
- 所有原有刷新调用均通过 `jxp_refresh_route_missions_effect` 汇入该隐藏事件；路线的 tag、宗教、flag、政府改革与融合状态完成变更后，下一游戏日再重建任务树。
- `jxp_mission_refresh_pending` 防止同一效果栈重复排队，事件执行时自动清除。
- 新增 `jxp_migration_v023.1`，旧存档会进行一次路线状态整理并重新构建任务树。

### 任务拓扑重排

- 保留全部 187 个任务 ID，避免旧存档丢失已完成任务记录。
- 大名阶段改为领国、对外接触、家门特色三列交错结构，并继续叠加原版五列任务。
- 七个路线 tag 的前九行改为五列菱形建国基础：继承国土、两京、军役与礼仪汇入新国制，再向登记、财赋、火器、海路展开，最后合流为“新生日本”。
- 统一后的国家建设改为第 1、2 列相互依赖的梯形结构；宗教和国体路线在第 3–5 列形成分叉、交汇与终局节点。
- 王政复古日本现在也启用礼制支线，任务树不再缺失中央列。
- 开国路线把日本主线、东亚外交和太平洋扩张互相交叉，终局任务需要大陆、海洋和通商三方面共同推进。

### 终局国家理念

- `KJP/CJP/EJP/RFJ/SJP/IJP/WAK` 七组理念全部增强，并保持各自路线身份。
- 总计 121 个有效修正条目；每组恰有 7 条理念，至少 5 条理念包含双重修正。
- 改革宗日本原本无效的 Protestant `church_power_modifier` 已替换为 Reformed 可用的 `monthly_fervor_increase`。
- 审计发现并修正了错误键名：商品产出使用 `global_trade_goods_size_modifier`，海军传统使用 `navy_tradition`。
- 原版 `JAP_ideas` 已经具备纪律、侵略扩张、步兵作战和人力等强项，因此不覆盖原版；七个路线终局理念以其为基准做专业化正向增强。
