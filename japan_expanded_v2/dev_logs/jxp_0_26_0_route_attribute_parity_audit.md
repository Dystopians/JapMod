## 结论摘要

1. 九路线的五列任务树和可见改革数量已经满足结构门禁，但结构相等不等于内容等深。有效任务总量从王政复古的 `43` 到开国通商的 `64`，路线专属槽 `3..5` 从王政复古的 `15` 到开国通商的 `36`，相差 `2.4` 倍。
2. 路线事件总数被家系组合事件显著抬高。剥离共享家系/殖民事件后，朱子礼制有 `26` 个路线原生事件，王政复古为 `0`，锁国与开国各为 `1`；这是 `JXP-006` 当前最明确的内容深度短板。
3. 九路线当前各有 `3` 项真正注册并可见的改革；另有每路线 `34` 项、合计 `306` 项 dormant 旧定义。27 项可见改革本身以及以这些改革为正向 gate 的事件，对三项时代属性的直接改变均为 `0`，是 `JXP-014` 最明确的系统缺口。
4. 三项属性并非缺少非决议来源：任务、事件、政府机制按钮、幕府政策桥与三条长期投资链均会改变属性。但路线专属分布不均：吉利支丹专属任务没有天下秩序奖励，海教专属任务没有天皇裁可奖励，一向路线的直接路线事件没有海门外学变化。
5. 路线互斥主干总体闭合：九个正常路线选择、两项民众/海国建国决议、sanitize 与九个 debug 强制入口都先走统一清理。仍有两个脆弱点：`jxp_ikko.1` 与 `jxp_wokou.1` 自己会写路线 flag，却没有本地的“尚无路线”条件或清理调用；当前调用链安全，但直接调用或未来复用可能叠 flag。
6. 刀狩令存在可复现的重复风险。JXP 决议只排除了拥有 `shogunate` 改革的幕府将军，却没有排除 `daimyo_vassal` 或原版 `subject_sword_hunt` 修正。幕府执行原版刀狩令后，大名属国仍可再执行 JXP 刀狩令，叠加独立修正并再次增加天下秩序。

最优先的可实施补齐项不是新增内容，而是先关闭刀狩令重复：把 `jxp_decision_issue_sword_hunt` 限定为非大名属国，并在已有 `subject_sword_hunt` / `overlord_sword_hunt` 时不可用；随后增加一个静态回归测试，证明原版幕府行动覆盖期间 JXP 决议不会出现。

量化规则：

- **有效任务**：使用项目 Clausewitz parser 与 `missions.evaluate_potential`，按当前九个最终路线 profile 计算实际激活的五个 series；共享 slot 1/2 共 `28` 个任务，路线专属任务为 slots 3/4/5。

- **调试**：`强制/事件` 分别表示路线强制入口和直接触发本路线事件的 debug 决议数。
- **属性生产者**：只计实际调用 `jxp_add_*` / `jxp_subtract_*` 的独立任务、事件或交互 block；单纯阈值检查不计。路线属性矩阵不计所有路线共享的政府按钮、幕府桥与投资，以免公共来源掩盖路线专属短板。

## 互斥 gate 审计

### 已闭合部分

- `jxp_clear_all_route_flags_effect` 清除 9 个路线 flag 和 9 个路线 modifier，并联动旧路线改革清理。
- `jxp_realm.1` 的九个正常路线选项都要求尚无路线，执行时先清理再设置唯一 flag。
- 一向与倭寇的建国决议先调用统一清理，再设置路线 flag；两个前置接触决议互相排除对方路线/tag。
- `jxp_sanitize_route_state_effect` 以 final tag 优先、`else_if` 单分支重建路线，分支内先清理后重设。
- 九个 debug 强制路线 effect 都先走 `jxp_debug_clear_route_state_effect`。
- 当前主门禁已证明九路线 mission profile 没有同槽竞争、generic fallback 或失效前置，并模拟 10 个统一状态的改革可见性：每条已选路线只显示自己的 3 项改革。

### 残余风险

1. 非 debug 的 24 个直接 `set_country_flag = jxp_path_*` 写点中，22 个位于明确的清理后路径；两个例外是 `events/jxp_ikko_events.txt` 的 `jxp_ikko.1` 与 `events/jxp_wokou_events.txt` 的 `jxp_wokou.1`。它们当前只由已完成转换的 `jxp_change_to_ijp_effect` / `jxp_change_to_wak_effect` 或先强制路线的 debug 决议调用，所以现状不是已证实冲突；但事件自身没有防御性 gate，未来复用或直接触发可能叠加路线状态。
2. `jxp_can_use_overseas_expansion_trigger` 只硬排除锁国，并允许所有 JXP 核心 tag。因此 CJP、EJP、IJP 等也可进入 8 个海外决议。应把“所有非锁国日本可参与的东亚/天命内容”和“私人海外贸易、殖民、太平洋国家内容”拆成不同语义 trigger，避免开国身份被公共 gate 稀释。
3. 路线家系事件使九路线的事件总数看似接近，但这些事件依赖创始家来源；没有对应 origin 的存档不会获得同等事件深度。原生事件列更能反映真正的路线独立循环。

## 刀狩令重复风险

固定原版 `common/government_mechanics/17_shogunate.txt` 的 `sword_hunt` 会：

- 给幕府将军 `overlord_sword_hunt`；
- 给所有 `daimyo_vassal` 属国 `subject_sword_hunt`；
- 原版冷却为 10 年。

JXP 的 `events/jxp_shogunate_policy_events.txt` 读取这两个修正：将军获得天下秩序 `+10`，大名属国获得天下秩序 `+5`，并用独立 flag 防止同一轮 bridge 重复结算。

但 `decisions/jxp_polity_decisions.txt` 的 `jxp_decision_issue_sword_hunt` 只在 `potential` 中写了 `NOT = { has_reform = shogunate }`。因此：

1. 幕府将军不会同时看到 JXP 决议，这一侧已闭合；
2. 大名属国本来就没有 `shogunate` 改革，收到 `subject_sword_hunt` 后仍符合 JXP 决议的路线/政体身份；
3. 大名可再支付军点，取得独立的 `jxp_sword_hunt_order`，并额外获得天下秩序 `+10`；原版属国惩罚与 JXP 国家奖励会同时存在。

建议的最小修复合同：

- JXP 决议 `potential` 明确排除 `is_subject_of_type = daimyo_vassal`；
- 防御性排除 `has_country_modifier = subject_sword_hunt` 与 `has_country_modifier = overlord_sword_hunt`；
- 保留 `NOT has_reform = shogunate`；
- 新增静态测试，要求上述三类原版幕府状态不能进入 JXP 刀狩令，同时独立、非幕府的统一日本仍可用该决议。

## 建议实施顺序

1. **先修刀狩令重复**：改动最小，直接对应 `JXP-014` 的明确验收句，且可完全静态回归。
2. **给王政复古补一个原生事件小循环和一个原生决议**：围绕国司巡察、禁里财政、海疆敕使做进入—取舍—冷却，至少提供一个海门外学/天下秩序的真实权衡，并增加对应 debug 直发入口。这一切不需要改动已经稳定的五列拓扑。
3. **把 27 项可见路线改革接入时代属性**：优先采用窄 gate、长冷却、可选择的低频 reform pulse，而不是无条件月增长；每路线至少让其三项改革合计覆盖两项时代属性，并为第三项保留有代价选项。
4. **补齐 debug 不对称**：王政复古从 `0` 个事件直发入口补起，然后补锁国/开国与一向/倭寇；目标是每路线至少一个“原生事件”、一个“属性权衡”、一个“路线后期事件”入口。
5. **拆分海外语义 gate**：保留共同东亚/天命内容，但把殖民、私人贸易和海国循环限定到适合的路线或明确的高海门外学/殖民者条件。
