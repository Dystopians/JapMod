# 日轮诸道：日本扩展风味包 阶段性报告

更新时间：2026-07-09
当前版本：0.5

## 本次重点

0.5 以“扩展任务树长度与广度”为核心，新增了三个高位任务槽：

- `slot = 13`：宗教/路线条件分支列。
- `slot = 14`：统一后国内制度、市场与学问列。
- `slot = 15`：北方边疆、海防与东海外交列。

本次没有使用 `replace_path`，没有覆盖原版日本任务或事件，仍保持独立追加式结构。

## 新增任务树

新增文件：

- `missions/jxp_11_branching_missions.txt`

宗教与路线分支：

- 神道/锁国/王政/倭寇兼容分支：社领账册、伊势参宫道、神社与城下、裁定神国异闻、神州诸岛。
- 基督教分支：港町信徒簿、假名教义书、教会与朝仪、殉道者与商人、十字日轮国。
- 朱子儒教分支：藩校考课、礼制户籍、神儒合礼、礼使往还、礼制国家。
- 回教海门分支：港町清真簿、港市法官、南海经纪、洁食仓法、南海海法。
- 一向宗民众分支：门徒名帐、寺内町市令、惣村誓纸、禁里与门徒、万民盟约。

通用扩展列：

- 国内制度列：大坂米账、城下诸市、诸藩学网、长崎译馆、银丝航路、三都账法。
- 边疆外交列：北海奉行、松前约书、海岸烽燧、对马译官、琉球使录、东海约法。
