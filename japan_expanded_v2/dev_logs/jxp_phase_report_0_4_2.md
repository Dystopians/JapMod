# 日轮诸道：日本扩展风味包 阶段性报告

更新时间：2026-07-09
当前版本：0.4.2

## 本次改动

0.4.2 基于 0.4.1 的低频时代属性纠偏事件，补充了第二选项，使其不再只是通知玩家，而是允许玩家代表国家意志介入。

涉及文件：

- `events/jxp_balance_events.txt`
- `localisation_source/jxp_11_l_english_utf8_source.yml`
- `localisation/jxp_11_l_english.yml`
- `descriptor.mod`
- `../japan_expanded_v2.mod`

## 设计调整

每个纠偏事件现在有两个方向：

- 默认选项：顺应制度惯性，将对应时代属性轻微拉回中间。
- 第二选项：坚持当前路线倾向，保留或强化极端方向，同时获得不同的短期收益或承担名分、点数、威望等代价。

具体事件：

- `jxp_balance.1` 天下秩序过高：可放缓法度，也可维持严令。
- `jxp_balance.2` 天下秩序过低：可重书村法，也可暂许乡里旧例。
- `jxp_balance.3` 天皇裁可过高：可减少朝廷日常裁决，也可借名分速断国政。
- `jxp_balance.4` 天皇裁可过低：可遣使修礼，也可暂缓朝仪处理急政。
- `jxp_balance.5` 海门外学过高：可审定译书港规，也可继续保护商路。
- `jxp_balance.6` 海门外学过低：可收录漂着之书，也可焚箱禁言。

## 技术说明

- 冷却 flag 与隐藏冷却事件已移入 `hidden_effect`，减少事件 tooltip 噪音。
- 仍沿用既有 `jxp_add_*_effect` / `jxp_subtract_*_effect`，确保脚本变量与政府机制 UI 同步。
- 每个事件仍保持独立 20 年冷却，不增加触发频率。
- 文案只表达政策选择，不直接描述机械收益或阈值。

## 后续建议

类似思路可以逐步扩展到部分路线事件和投资完成事件，但不要把所有风味事件都改成多选。适合加选择的事件应满足：

- 国家确实能通过政策、财政、礼制、港规或武力介入。
- 两个选项都应有历史合理性。
- 至少一个选项应保留机制惯性，另一个选项体现路线偏执或国家意志。
